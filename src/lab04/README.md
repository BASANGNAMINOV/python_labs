# ЛР4 — Файлы: TXT/CSV и отчёты по текстовой статистике
## Задание A — модуль `src/lab04/io_txt_csv.py`

В задании  реализован модуль для чтения текстовых файлов и записи данных
в CSV. Функция `read_text` читает весь файл и возвращает его содержимое
одной строкой. По умолчанию используется кодировка UTF-8; при необходимости
можно указать другую, например `encoding="cp1251"`. Ошибки отсутствующего
файла и неподходящей кодировки не скрываются: возникают `FileNotFoundError`
и `UnicodeDecodeError` соответственно.

Функция `write_csv` создаёт или перезаписывает CSV-файл в UTF-8. Она может
записать заголовок первой строкой, проверяет, что длины строк данных
одинаковы и совпадают с длиной заголовка, если он задан. Если длины
различаются, возникает `ValueError`. Нужные родительские папки создаются
автоматически. При пустом списке данных записывается пустой файл либо только
заголовок, если он указан.

## Задание B — скрипт `src/lab04/text_report.py`

В задании  реализован скрипт `src/lab04/text_report.py`, который читает текстовый файл, нормализует и токенизирует его, считает частоты слов и записывает результат в CSV-файл `word,count`. При этом слова сортируются по убыванию частоты и затем по алфавиту. В консоль выводится общее число слов, число уникальных слов и топ-5 самых частых слов. Скрипт использует функции из `src/lib/text.py` из ЛР3. Если файл не найден, программа сообщает об этом и завершает работу; при пустом вводе сохраняется корректный отчёт с заголовком.Кодировка прописана в коде, по умолчанию `utf-8`.

## Краевые случаи

- **Пустой файл** — если входной файл пустой, в `report.csv` будет только заголовок `word,count`, без записей. В консоли количество всех и уникальных слов будет равно нулю, а после `Топ-5:` ничего не выведется.

- **Файл не найден** — если входного файла нет по указанному пути, программа выведет сообщение `Ошибка: файл не найден: <путь>` и завершит работу.

- **Кодировка файла** — по умолчанию программа читает файлы в кодировке `UTF-8`. Если файл сохранён в другой кодировке, например `cp1251`, нужно поменять значение `ENCODING` в начале файла `text_report.py`.

- **Изменение путей** — пути к входному и выходному файлам задаются в переменных `INPUT` и `OUTPUT`. Если нужно использовать другие файлы, достаточно изменить эти значения.

## Как запустить text_report.py

Для запуска нужно открыть терминал в корне проекта, где находится папка `src`, и выполнить команду:

```bash
python -m src.lab04.text_report
```
