# ЛР4 — Файлы: TXT/CSV и отчёты по текстовой статистике
## Задание A — модуль `src/lab04/io_txt_csv.py`

В задании  реализован модуль для чтения текстовых файлов и записи данных
в CSV. Функция `read_text` читает весь файл и возвращает его содержимое
одной строкой. По умолчанию используется кодировка UTF-8; при необходимости
можно указать другую, например `encoding="cp1251"`. Ошибки отсутствующего
файла и неподходящей кодировки не скрываются: возникают `FileNotFoundError`
и `UnicodeDecodeError` соответственно.

Функция `write_csv` создаёт или перезаписывает CSV-файл в UTF-8. Она может
записать заголовок первой строкой, проверяет, что длины строк данных
одинаковы и совпадают с длиной заголовка, если он задан. Если длины
различаются, возникает `ValueError`. Нужные родительские папки создаются
автоматически. При пустом списке данных записывается пустой файл либо только
заголовок, если он указан.
