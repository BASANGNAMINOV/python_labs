# Python Labs

Практические задания по Python. Скрипты находятся в `src`, а скриншоты их работы - в `images`.

## Структура

```text
python_labs/
|-- README.md
|-- src/
|   |-- lab01/
|   |   |-- ex01.py
|   |   |-- ex02.py
|   |   |-- ex03.py
|   |   |-- ex04.py
|   |   `-- ex05.py
|   |-- lab02/
|   |-- ...
|   `-- lab10/
`-- images/
	|-- lab01/
	|   |-- img01.png
	|   |-- img02.png
	|   |-- img03.png
	|   |-- img04.png
	|   `-- img05.png
	|-- lab02/
	|-- ...
	`-- lab10/
```

## Запуск

Из корня проекта выполните:

```powershell
python .\src\lab01\ex01.py
python .\src\lab01\ex02.py
python .\src\lab01\ex03.py
python .\src\lab01\ex04.py
python .\src\lab01\ex05.py
```
